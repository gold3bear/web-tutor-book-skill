# 教程书页纲格式

## 规划原则

- 一章回答一个大问题；一张语义页完成一个阅读任务。
- 页数由内容决定，不预设上限。
- 每页列出它覆盖的源内容块 ID；没有块 ID 的新增解释必须标为 `editorial`。
- 长段落、代码和表格允许续页，不能压缩成一句摘要。
- 每个视觉页列出 `visual_purpose`、`source_blocks`、`asset_source` 与紧邻的完整正文页；不能只写“加一张图”。
- 在页纲中区分 `visual-companion` 与 `source`。图会挤压文字时，视觉页在前、完整说明页在后，不把两者硬塞进同一固定页面。

## `book-plan.md` 必备结构

```markdown
# 书名

## 编辑契约
- 内容模式：完整保留
- 源材料：source.md
- 允许省略：无
- 输出：翻页 HTML + 连续阅读 + 可选 EPUB 3

## 全书结构

### 01 章节标题

#### 01-01 · chapter-open · 页面标题
- 阅读任务：读者在这一页理解什么
- source_blocks：B0001, B0002
- 内容：保留哪些段落、数字、例子和限制
- 视觉：可选；说明关系，不替代文字
- 移动端：固定页 / 全高页 / 可滚动正文

#### 01-02 · exposition · 页面标题
- 阅读任务：……
- source_blocks：B0003, B0004
- 内容：……

#### 01-02-cont-1 · continuation · 页面标题（续）
- 阅读任务：完成上一页的论证
- source_blocks：B0004, B0005
- 内容：……

#### 01-02-visual · visual-companion · 页面标题
- 阅读任务：读者通过图理解什么关系
- source_blocks：B0003, B0004
- visual_purpose：解释结构，不替代完整步骤
- asset_source：原创流程图 / 用户提供截图路径 / 公开页面与抓取日期
- 相邻正文：01-02、01-02-cont-1
- 容量策略：独立固定页；正文不与图竞争高度

## 覆盖摘要
- 源内容块：N
- 已映射：N
- 用户批准省略：0
- 待处理：0
```

## 推荐页型

- `cover`：书名、作者/来源、版本；不承载正文。
- `chapter-open`：章节问题、背景与学习目标。
- `exposition`：完整解释性正文，可包含边注和引用。
- `dialogue`：人类输入与 Agent 行动的对应关系。
- `process`：流程图加完整步骤文字。
- `evidence`：证据、来源、数据口径和反例。
- `code`：完整代码、复制按钮、说明与预期输出。
- `table`：完整表格；窄屏横向滚动或转换为可访问定义列表。
- `checklist`：可执行检查项和通过条件。
- `continuation`：同一主题的自然续页。
- `appendix`：大表、原始清单、参考资料和完整对话。
- `conclusion`：总结章节，不替代前文细节。

## 页纲自检

- 每个源内容块是否至少出现一次？
- 所有步骤、代码和表格是否完整？
- 图解旁是否仍能读到完整解释？
- 是否因为追求统一页数或视觉留白而删掉内容？
- 手机容量不足时是否采用全高页或续页？
- 是否同时规划连续阅读模式？
- 真实截图是否与本页教学任务直接相关、清晰且可追溯？
- 是否存在“图占空间后把正文挤出页面”的风险？
- 是否把编辑态标签、素材类型徽标或无效帮助文字误当成读者内容？
