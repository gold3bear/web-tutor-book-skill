## 1. 保真目标

网页教程书的任务是**重新组织阅读体验**，不是把原文改写成演示文案。默认目标是信息保留率 100%。排版、标题层级、图解和顺序调整可以优化，但所有能影响理解、复现或判断的信息必须保留。

必须保留：

- 事实、数字、日期、限定词和数据口径；
- 操作步骤、前置条件、失败处理和验证方法；
- 代码、命令、参数、路径和输出；
- 表格中的行列、脚注、引用和来源；
- 反例、例外、风险提示和“不应该做什么”；
- 用户与 Agent 的关键对话，尤其是选择和确认。

## 2. 内容块与台账

用 `source_coverage.py init` 将源材料拆成稳定内容块。台账是内容覆盖的唯一真相源，不是页纲的替代品。

每个块包含：

- `id`：稳定编号；
- `kind`：heading、paragraph、list-item、code、table 等；
- `text` 与 `sha256`：检测源内容漂移；
- `page_ids`：承载该内容的语义页；
- `disposition`：内容的保留方式；
- `retention_note`：改写、图解或附录时说明完整内容在哪里；
- `approval_note`：用户批准省略时的证据。

不要手工删除台账块。源材料变化后重新初始化，并对比变更。

## 3. 可接受与不可接受的编辑

可以：

- 修正明显错别字并记录；
- 拆分过长段落，但不减少句子和限定条件；
- 把步骤改成有序列表；
- 增加解释、图解、导航标题和交叉引用；
- 将完整大表移到附录，正文保留结论和明确链接；
- 让相同内容同时出现在翻页与连续阅读模式。

不可以：

- 用一句“核心观点”替代多个来源段落；
- 为适配一页而删除例子、参数、条件或风险；
- 用流程图替代完整操作文字；
- 把表格仅改成三个数字卡片；
- 将代码截断为省略号；
- 未经批准把内容标记为“重复”并删除；
- 将 Agent 的推断混入原文而不标识。

## 4. 页面容量决策树

当内容超过页面容量时，按顺序选择：

1. 这个主题能否自然拆成两个阅读任务？能则创建新语义页。
2. 不能拆主题但段落很长？创建同标题续页，例如 `03-04-cont-1`。
3. 是代码、表格、长引用或参考资料？使用页内滚动，并提供“展开/复制/连续阅读”入口。
4. 是手机屏幕导致容量不足？手机改用接近全高的 EPUB 式页面，不要继续缩字。
5. 内容需要搜索与长时间阅读？保留翻页导读，同时在连续阅读模式完整呈现。
6. 仍希望省略？停下并请求用户明确批准。

禁止把缩小字体作为首选方案。正文字号低于可读阈值时，应增加页数。

## 5. 覆盖审计

规划前执行 `init`，规划后和最终交付前执行 `audit`。

通过条件：

- 源文件哈希与块哈希一致；
- 所有块都有合法 `disposition`；
- 除用户批准省略外，每个块至少有一个 `page_id`；
- 非原样呈现的块都有 `retention_note`；
- 默认不存在 `user-approved-omit`；
- 任何批准省略都有可追溯 `approval_note`。

自动审计只能证明“已分配”，不能证明改写等义。最终还需要逐章人工/Agent 对照复核。

## 6. 常见失败模式

### 把书当成视频

症状：每页只有一句大字，原文细节被移到不存在的“讲解”中。修复：恢复正文页和续页；网页书没有口播替代文字。

### 把语义页当成固定字数卡片

症状：所有页结构相同，段落被统一压缩。修复：允许 exposition、code、table、continuation 等不同页型。

### 图解替代证据

症状：流程看起来清楚，但参数、来源和异常处理消失。修复：图解与完整文字共存，或在紧邻续页保留。

### 手机裁切后继续缩字

症状：手机正文过小仍有溢出。修复：手机使用全高阅读页；必要时再拆页。

## 7. 术语与渲染保真

内容块完整不等于读者看到的内容正确。开发前建立一份短术语表，记录产品名、人物名、品牌大小写、Agent 称谓和不能改动的代码、URL、文件名。例如确定产品名与 Agent 称谓后，在正文、标题、图题、替代文本和元数据中统一；批量替换不得影响代码围栏、链接和路径。

把 Markdown 作为结构输入而不是最终文字。最终阅读表面不得裸露：

- `**粗体**`、反引号代码围栏或 Markdown 链接语法；
- 未解析的 HTML 实体或模板占位符；
- 仅供编辑协作的“完整原文”“下一页继续”“页面截图”等说明；
- 已删除功能遗留的按钮、标签或帮助文案。

最终同时检查 DOM 可见文字与 PDF 提取文字。源码搜索只能证明字符串存在与否，不能证明它是否被错误显示；浏览器检查也不能替代 PDF 文本层检查。
