# Web Tutor Book Landing Page Brand Spec

## Positioning

- Role: the publishing editor-in-chief inside a local Agent.
- Promise: preserve the manuscript, shape the learning experience, audit the result, and sign off publication readiness.
- Primary conversion: download the complete Skill archive.
- Secondary conversion: copy an installation prompt for a local Agent.

## Visual language

- Direction: technical publishing house × modern Agent tool.
- Paper: `#f2eee3`
- Sheet: `#fbf8f0`
- Ink: `#1d1b18`
- Editorial red: `#8f2f2f`
- Proof gold: `#b69b68`
- Rules and muted copy: `#cfc5b3`, `#70695f`
- Display type: `Songti SC`, `STSong`, `Noto Serif CJK SC`, serif.
- Body type: `PingFang SC`, `Microsoft YaHei`, sans-serif.
- Utility type: `SFMono-Regular`, `Menlo`, monospace.

## Brand assets

This project has no separate graphic logo. Use the editorial wordmark `WEB TUTOR BOOK`; do not fabricate a logo.

Real product imagery:

- `assets/real-book-cover.png`: completed Web Tutor Book reader cover.
- `assets/real-reader-desktop.png`: completed desktop reading view.
- `assets/real-reader-mobile.png`: completed mobile reading view.
- `assets/real-pdf-contact-sheet.jpg`: rendered PDF page contact sheet.

The assets are real outputs from the LoomLoom × WorkBuddy tutorial-book case. They are product evidence, not decorative mockups.

## Interaction

- Motion is restrained: paper lift, short opacity transitions, button press.
- All touch targets are at least 44px.
- The primary CTA remains visible in the first mobile viewport and in a bottom mobile action bar.
- Respect `prefers-reduced-motion`.
