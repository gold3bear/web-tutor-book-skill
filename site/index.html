01 · EDITOR-IN-CHIEF

生成页面很容易，对出版结果负责很难

主编不以“页面已经生成”为完成信号，而以内容完整、读者可执行、成品可复验为交付标准。

普通文档生成

  • 自动摘要长文，内容缺失难以追踪
  • 为适应固定页面而压缩正文
  • 视觉完成后直接交付
  • 只有成品，没有审计证据

Web Tutor Book 主编

  • 保存原稿，并为每段内容建立台账
  • 页面不够就增加语义页与续页
  • 内容、教学、技术和视觉共同验收
  • 提供问题级别、修复方式和复验条件

它卖的不是排版，而是出版责任。

02 · TWO COMMISSIONS

制作新书，或审查已有文档

同一位本地主编，接受两种不同委托。桌面端并排比较，手机端通过标签切换。

COMMISSION A · CREATE

把业务材料编辑成可发布的教程书

接收 Markdown、PDF、DOCX、聊天记录或知识库素材，完成网页翻页版、连续阅读版、可搜索 PDF 与 EPUB。

原始材料 → 内容台账 → 编辑制作 → 多端验收 → 出版签发
COMMISSION B · AUDIT

判断现有教程是否真的可以发布

审查 PDF、HTML 或 Markdown，按照目标用途检查教学闭环、事实、链接、视觉与技术质量。

成品文档 → 技术扫描 → 全书审读 → P0/P1/P2 → 修复清单

05 · OPTIONAL CLOUD REVIEW

云端负责批量审计问题，本地主编负责决策

LoomLoom 批量视觉审计是可选的外部审稿能力。它提出候选，本地 Agent 必须回看高清原图后才能进入修复清单。

01 · PREPARE准备脱敏书页

本地主编完成构建、页面编号和安全预检。

02 · DISCOVER云端并行发现

批量寻找遮挡、模板残留、图片误用与排版异常。

03 · VERIFY回看高清原图

接受、重述或驳回云端候选，防止误判原因。

04 · SIGN OFF主编最终签发

根据全部本地证据决定修改方式与发布结论。
